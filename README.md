Sistema de Gestão de Ordens de Serviço - Oficina Mecânica

Cliente: Seu Osvaldo (Mecânica)

Objetivo do Sistema:

Prover uma solução de gestão rápida e otimizada para uso em dispositivos móveis dentro da oficina. O sistema permite o cadastro de ordens de serviço, cálculo automático de custos de peças e mão de obra (aplicando a taxa adicional de 20% para veículos importados) e controle de status de atendimento das OS.
